# Privacy

Mount and fstab output can expose usernames, home paths, internal application layout, container identifiers, network server/share names, removable-media labels, and storage identifiers. Review output before sharing it.

The program has no telemetry, persistence, network access, DNS lookup, or output-file feature. It writes results to stdout and diagnostics to stderr. Redirected files are created by the caller's shell and permissions therefore depend on the caller's umask.
